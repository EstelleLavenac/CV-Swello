# Estelle × Swello

Landing de candidature d'Estelle Lavenac, designer graphique senior (print, web & motion), pour Swello (Toulon).

« Une designer simple & efficace pour gérer vos visuels, toujours avec amour. »

- Page autonome : un seul `index.html`, aucune dépendance à installer.
- Animations en CSS ; les yeux de la mascotte suivent le curseur et le compteur de likes grimpe (JavaScript léger).
- Titres en FatFrank (si installée, sinon Lilita One), textes en Roboto Condensed. Palette calée sur la marque Swello (indigo, rose, claret).
